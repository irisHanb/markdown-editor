# Data Model: 사이드바 2분할 레이아웃·리사이즈 (M2-a)

## Layout (레이아웃 설정)

| 필드 | 타입 | 범위 | 기본값 | 키보드 단위 |
|------|------|------|--------|------------|
| `sidebar` | number (px, 정수) | 180–480 | 260 | 10 |
| `editor` | number (%, 정수) | 30–70 | 50 | 5 |

- 영속 위치: `localStorage["mdeditor:layout:v1"]`, 값은 JSON `{"sidebar":260,"editor":50}`.
- 브라우저당 1개. 문서 저장본(`mdeditor:v1`)과 별개입니다.
- 프리뷰 비율은 저장하지 않습니다(`100 - editor`).

## 복원 규칙 (FR-014)

| 저장값 | 결과 |
|--------|------|
| 키 없음 | 기본값 `{260, 50}` |
| JSON 파싱 실패 | 기본값 |
| 필드가 숫자가 아님(문자열·null·NaN) | 그 필드만 기본값 |
| 범위 밖 숫자(예: `sidebar: 600`) | 가장 가까운 한계값(480) |
| 소수(예: `sidebar: 255.7`) | 반올림(256) |
| 저장소 접근 예외 | 기본값 |

## 상태 전이

```
[열기]      저장값 복원 → CSS 변수 적용 (첫 화면 전, research R3)
[끌기 중]   값 = clamp(포인터 위치 계산값) → CSS 변수 갱신 (저장 안 함)
[끌기 종료] 마지막 값 저장
[키 입력]   값 = clamp(값 ± 단위 | 최소 | 최대) → CSS 변수 갱신 → 저장
```

## 화면 적용 (파생 값)

| 값 | 계산 |
|----|------|
| 사이드바 실제 너비 | `max(180px, min(sidebar px, 창 너비 - 480px))` — 저장값은 바꾸지 않음 |
| 에디터·프리뷰 칸 | 에디터 `editor%`, 프리뷰 `100 - editor%`, 각 최소 240px |
