**Feature Branch**: `007-usability-fixes` (git 작업 브랜치: `feature/init`)

**Created**: 2026-11-13

**Status**: Draft

**Input**: 사용자 수동 검증 피드백(2026-11-13) 4건 — "기능아이콘 클릭후 편집해야하는 자리에 focus 처리",
"강제줄바꿈 아이콘 클릭시 미리보기에서는 아무 출력물도 나오지 않게", "모든 피드백 메시지(저장할때 등등)는

## Requirements

- **FR-001**: 커서만 있는 상태(선택 없음)에서 줄 접두 버튼(H1–H3·인용·글머리 목록·번호 목록·작업 목록)을 누르면,
  커서는 같은 글자 앞에 그대로 남아야 합니다(접두가 붙거나 빠진 길이만큼 이동). 빈 줄이면 접두 바로 뒤입니다.
  예: `he|llo` → [H1] → `# he|llo`, `|` → [작업 목록] → `- [ ] |`. 선택이 있으면 지금처럼 바뀐 줄 전체를 선택합니다.
- **FR-002**: [표]를 누르면 표를 넣고 첫 제목 칸 글자("제목")를 선택해야 합니다.
- **FR-003**: 선택 없이 [자동 링크]를 누르면 `<https://>`를 넣고 커서를 `https://` 바로 뒤에 둬야 합니다. 선택이 있으면
  지금처럼 선택 글자를 감쌉니다.
- **FR-004**: [강제 줄바꿈]은 줄 끝 공백 2개 + 줄바꿈(`"  \n"`)을 넣어야 합니다. 다음 줄에 글자가 없으면 미리보기에
  아무것도 더해지지 않고, 다음 줄에 글자를 쓰면 `<br>`로 줄이 바뀝니다(CommonMark §6.7). M2-b 결정(백슬래시 방식,
  `specs/003-full-toolbar` US1-4)을 대체합니다.
- **FR-005**: 툴바 버튼을 누른 뒤 키보드 포커스는 편집기에 있어야 합니다(현재 동작 유지, 회귀 금지).
- **FR-006**: 저장 성공·저장 실패·이름 자동 변경 저장·[취소]로 되돌림 알림은 모달 대화상자로 보여야 합니다. 대화상자는
  제목·문구·[확인] 버튼 1개를 갖고, [확인]·Esc·바깥 클릭으로 닫히며, 닫히면 포커스가 열기 전 요소로 돌아갑니다.
  자동으로 사라지지 않습니다. M1 FR-014(토스트 1,900ms)를 대체합니다.
- **FR-007**: 상단 로고(아이콘 + "Markdown Editor")는 대시보드(`#/dashboard`)로 가는 링크여야 합니다. 이동은 M6 저장 확인을
  거칩니다(저장하지 않은 변경이 있으면 3버튼 확인).

## Assumptions

- 입력 칸 바로 아래 오류(문서 바 "폴더를 선택하십시오", 사이드바 이름 오류)는 해당 칸과 묶인 검증 메시지라 모달로 바꾸지
  않습니다. 오류 칸에 포커스를 두고 고치게 하는 M6 흐름을 유지합니다.
- 저장소를 열 수 없을 때 화면 위에 계속 보이는 안내 띠(M3)는 일시 알림이 아니라 상태 표시라 그대로 둡니다.
- 알림 모달은 기존 확인 대화상자와 같은 시각(단색·1px 테두리·그림자 없음)을 씁니다.

## Success Criteria

- **SC-001**: FR-001–FR-004 기대값이 플러그인 단위 테스트로 고정됩니다.
- **SC-002**: 화면에 토스트 요소가 남아 있지 않고, 알림 4종이 모두 모달로 뜹니다(수동 검증).
- **SC-003**: 기존 테스트 회귀 0건.
